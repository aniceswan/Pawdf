Pawdf

Offline PDF toolkit

Every PDF job,
done on your desk.

Split, merge, reorder, compress and convert without uploading a single page. Nothing leaves this machine.

Files are merged top to bottom. Reorder them in the list on the left.

A PDF stores glyphs, not paragraphs, so structure is reconstructed by inference. Typical documents come out well; tables and multi-column layouts do not.

Converted by Pawdf itself - no Word and no LibreOffice involved. Footnotes, headers and footers are not carried over.

Cropping hides content, it does not remove it. Anything outside the new edge is still in the file and comes back if the crop is undone.

Rebuilds a PDF whose structure is damaged, which is what a failed download or an interrupted save leaves behind. Content that was genuinely lost cannot be brought back.

Also allow These are requests, not locks. Compliant readers obey them; others ignore them. Only the password is real protection.

A watermark is drawn over the page. The content underneath is untouched and reappears if the mark is removed, so this labels a document rather than hiding anything in it.

This places a picture on the page. It is a visual mark, not a cryptographic signature: it does not prove who signed or detect later edits.

Headings, bold, italic and lists are reconstructed from font sizes and line starts. Images are written to a folder beside the .md file and linked relatively. Tables and multi-column layouts are not attempted.

One section per visible sheet. Calculated cells show their last saved value, so a workbook whose formulas were never calculated will have gaps. Charts, images and cell colours are not carried over.

One slide per page, at the deck's own shape. Text and pictures are placed where the file says; theme styling, animations, charts and SmartArt are not reproduced.
